## Introduction
{:#introduction}

Knowledge graphs expressed in [RDF](cite:cites spec:rdf) are a central pillar of neuro-symbolic AI:
techniques such as [GraphRAG](cite:cites graphrag), [GRASP](cite:cites grasp), and the [Model Context Protocol (MCP)](cite:cites mcp)
make it increasingly common for multiple agents to read from and write to the same RDF knowledge graph simultaneously —
one agent enriches the graph while another reasons over it, and a third corrects errors it discovers.

In decentralized data ecosystems — such as [Solid](cite:cites solid), [IDSA](cite:cites idsa), and [Gaia-X](cite:cites gaia-x) —
each participant governs their own data without relying on a central authority.
A critical challenge is concurrent offline editing: when two agents independently modify the same resource, their updates collide.
Asking an agent to resolve such conflicts manually is not always desirable — an agent that has been offline may struggle to grasp how much has changed.
[Conflict-free Replicated Data Types (CRDTs)](cite:cites CRDTs) offer a principled solution,
guaranteeing that any two replicas converge to the same state through well-defined merge algorithms, with no coordination required.

Solutions have been proposed for [RDF-based CRDTs](cite:cites rdf-crdt) and even [CRDTs in Solid](cite:cites solid-crdt-yjs),
but the introduction of [RDF 1.2](cite:cites rdf-1-2) opens new possibilities.
RDF 1.2's triple terms — where the object of a triple can itself be a triple — enable efficient,
first-class modelling of state-based CRDTs directly within RDF datasets, without any external bookkeeping.

In this paper, we present a **state-based add-wins set CRDT** modelled entirely in RDF 1.2.
All bookkeeping stays within the same dataset,
**enabling atomic updates** on the resource without server intervention,
and allowing **both CRDT-aware and CRDT-unaware clients** to coexist without friction.
Working at the quad-store level further **enables CRDT abstraction inside query engines**,
as demonstrated by our [proof-of-concept implementation](https://github.com/jitsedesmet/comunica/pull/9){:.mandatory} in [Comunica](cite:cites comunica) —
meaning agents can query and update a conflict-free knowledge graph through standard interfaces,
without any awareness of the underlying CRDT machinery.
