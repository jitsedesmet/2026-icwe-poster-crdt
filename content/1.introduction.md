## Introduction
{:#introduction}

The paradigm of neuro-symbolic AI aims to improve the accuracy, trustworthiness, and explainability of AI agents by grounding their reasoning in structured symbolic knowledge.
[Knowledge graphs expressed in RDF](cite:cites spec:rdf) have become a central pillar of this approach:
techniques such as [GraphRAG](cite:cites graphrag) augment LLM answers with retrieved graph structures,
zero-shot SPARQL generation with [GRASP](cite:cites grasp) allows agents to query arbitrary knowledge graphs without fine-tuning,
and the recently introduced [Model Context Protocol (MCP)](cite:cites mcp) connects LLM agents to live knowledge bases — including knowledge graphs via SPARQL-based tools — without pre-computation.
These developments make it increasingly common for multiple agents to read from and write to the same RDF knowledge graph simultaneously:
one agent enriches the graph while another reasons over it, and a third corrects errors it discovers.

At the same time, decentralized data ecosystems — such as
[Solid](cite:cites solid), [IDSA](cite:cites idsa), and [Gaia-X](cite:cites gaia-x) —
in which each participant governs their own data without relying on a central authority, are gaining popularity.
A critical challenge in these ecosystems is concurrent offline editing of shared data.
When two agents independently modify the same resource without coordination, their updates collide.
Any offline-first system needs a strategy to recover from such collisions,
whether by dropping the conflicting update, prompting the user, or resolving it automatically.

In agentic systems, asking the agent itself to resolve conflicts may be possible, but is not always desirable.
An agent that has been offline for some time may struggle to understand how much has changed and reconstruct the right merge decision — making automated, principled conflict resolution preferable.
[Conflict-free Replicated Data Types (CRDTs)](cite:cites CRDTs) are a well-established approach to this problem:
they guarantee that any two replicas converge to the same state through well-defined merge algorithms, with no coordination required.

Solutions have been proposed for [RDF-based CRDTs](cite:cites rdf-crdt) and even [CRDTs in Solid](cite:cites solid-crdt-yjs),
but the introduction of [RDF 1.2](cite:cites rdf-1-2) opens new possibilities.
RDF 1.2's triple terms — where the object of a triple can itself be a triple — enable efficient, first-class modelling of state-based CRDTs directly within RDF datasets, without any external bookkeeping.

In this paper, we present a state-based add-wins set CRDT modelled entirely in RDF 1.2.
All bookkeeping stays within the same dataset, allowing both CRDT-aware and CRDT-unaware clients to coexist without friction.
Working at the quad-store level further enables CRDT abstraction inside query engines,
as demonstrated by our proof-of-concept implementation in [Comunica](cite:cites comunica) —
meaning agents can query and update a conflict-free knowledge graph through standard interfaces,
without any awareness of the underlying CRDT machinery.
